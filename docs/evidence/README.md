# Evidencia visual

Esta carpeta está reservada para capturas de validación del proyecto.

Antes de agregar una imagen:

- Oculta contraseñas, cadenas de conexión y datos personales.
- Recorta áreas ajenas a la validación.
- Utiliza nombres numerados y descriptivos.
- Registra en `../EVIDENCE.md` qué criterio demuestra.

complementan para la presentación académica.
